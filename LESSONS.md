# Lessons learned

Distilled from the journals of three apps. One line per lesson: **what happened → what to do**.
Details are in the indicated stage.

## Product and PRD (stages 1 to 3)

- PRD ignored Play's 14-day closed test → check current store rules for the account type during technical review. (03)
- PRD assumed Functions on Firebase's free plan → check the free plan against each service. (03)
- PRD assumed a Mac for builds → EAS Build compiles iOS in the cloud. (03)
- PRD requested a custom sync queue → Firestore's offline cache + trigger provide the same guarantee. (03)
- "Use without an account" rule came from a complaint about phone numbers → read the evidence behind the rule before paying its cost. (01)
- Superprompt discrepancies only surfaced when compared with another app's journal → always compare with the recipe and lessons. (01)
- Unmarked required field, hidden action → write each field's rule in the PRD before generating the screen. (02)
- Plan rule without an edge-state screen → screens for limits reached, blocking and returning to free. (02)
- Deletion screen without a "cancel deletion" state → every reversible action has a way back on screen. (02)
- Fictional date with the wrong weekday passed through 3 screens → check the weekday of every fixed date. (02)
- New idea midway through the process → inventory in a single source: a new screen costs one line. (02)

## Brand and screens (stages 4 to 6)

- Logo concept came out dark and blurry 2 times → fixed phrase "light background, no blur, no glow"; stop after 2 attempts and rewrite the concept. (04)
- Audience chose the logo the owner would not have picked → show 3 to 4 concepts to buyers. (04)
- Generator got the logo wrong on screens and the checker approved it → always paste the logo by script; fix the references too. (04, 06)
- Symbol read as "download" → test at 24 px next to system icons. (04)
- Web agent cannot see competitor icons → download store thumbnails and make a sheet. (04)
- Large batches approved on the first pass → approve 2 to 4 references per platform before the batch. (06)
- Same fictional person on different days → fixed fictional data per screen in the inventory. (06)
- Torn edge and invented button approved screen by screen → contact sheet with the entire journey. (06)
- Dark frame in 1 of 5 iOS screens → "no torn edges, no vignette" in the base prompt. (06)
- Header and logo invented by the generator → explicit "no logo". (06)
- Reviewer reads a journey, not a screen → flow map navigable in journey order. (06)
- Image outdated after code → image follows code in the same delivery; real screenshot replaces the concept. (06)

## Code (stages 8 and 9)

- Build broke with a forced targetSdk → do not override the Expo SDK default. (08)
- First EAS upload was 359 MB → `.easignore` before the first build. (08)
- Tests inside `app/` became routes and broke the Android build → tests live in `src/test`. (08)
- Library with C++ ran out of memory during build → test build for arm64 only. (08)
- Missing required dependency would crash the app on launch → `expo-doctor` for each native library. (08)
- Bare `lib/` in `.gitignore` ignored code → use a rule with a path. (08)
- Constant `KEY` triggered a secret alert → names such as `STORAGE_ENTRY`. (08)
- Route hidden inside Tabs failed to navigate on the web → Stack outside, tabs in `(tabs)`. (08)
- Direct `setState` in an effect blocked by React Compiler lint → store the value with the query key. (08)
- `Date.now()` blocked in the component body → receive `now` as a prop; also lets the test fix the date. (08)
- Each native module behind a port, with web and fake versions → preview and tests stay working without `if (Platform)`. (08)
- Notification scheduling from two places erased each other's notifications → identifier per owner (`owner:n`), cancel only that owner's. (08)
- Preference read once missed backup restoration → revision number in the data provider. (08)
- Saved state gained new fields → `schemaVersion` from the first document. (03, 08)
- Number in a list calculated in the app → comes ready in the document, maintained by the server. (03)
- Adding checks to the same rule exceeded Firestore's expression limit → separate rule branch; validate shape in the rule and business logic in zod. (03)
- `service` is a reserved word in Firestore rules → `d['service']`. (08)
- "Create only" rule broke upload retries → allow overwriting at the same index. (08)
- Function serving HTML with a copy of the site broke after a site-only deploy → fetch the shell from Hosting with a short cache. (08)
- Per-IP limit bypassed by calling the Function directly → global hourly cap in addition to the IP limit. (08)
- Webhook trusted → fetch state from the source and record the event version. (13)
- Audit record outside the transaction → same transaction as the change. (09)
- Firestore TTL never enabled → check the policy in the project, not just the field. (03)
- Switch that looked instant only persisted on "Save" → switch saves immediately; a form with a save action does not mix in on/off toggles. (09)
- Real error swallowed by a generic message → message near the button and code in the technical log. (15)

## Agents (working modes)

- Briefing without "pattern to follow" cost ~36% more → always point to a similar file. (modes)
- 680-line file → limit of ~250 lines in agent instructions. (09)
- Executor said "passed" without typecheck → reviewer runs the full typecheck. (09)
- Briefing contradicted the image → the briefing is wrong; use grep to check its claims. (09)
- "Implement the plan" without pasting the plan → every call is a new session. (modes)
- Truncated review found 2 of 12 holes → synchronization goes to review with the entire file. (09)
- Backend cross-review found concurrency bugs in almost every round → always worth it for new backend code. (09)
- Chained job in a loop died without output → one job per batch, checked on disk. (modes)
- `while pgrep -f` matched its own command and never ended → wait by PID or use `wait`. (modes)
- Agent stuck 2 times on the same test → the other takes over. (09)
- Site articles written by agents in parallel without false promises → briefing with a fixed list of "app facts". (14)

## Tests (stage 10)

- Fake accepted `undefined` that the native SDK rejects → the fake mirrors the SDK's rejections. (10)
- Triggers stalled rule tests → rules and Functions in separate runs. (10)
- New field disappeared on save → add it to the zod schema too; test saving and reading back. (10)
- CI in UTC and English broke dates → fixed `timezoneId` and `locale`. (10)
- Paused Playwright clock stalled axe → release the clock to measure. (10)
- 52×32 switch passed → measure touch targets in web E2E. (10)
- Hidden button in the stack was clicked → filter by visibility; run long E2E 4 times. (10)
- "Save password" dialog swallowed the tap in CI → disable autofill in the emulator. (10)
- Maestro does not scroll automatically → `scrollUntilVisible`. (10)
- Guided tip isolated the screen in Maestro → close the tip before checking. (10)
- Native E2E used up the CI quota → nightly and on demand after the initial phase. (10)
- E2E screenshot in offline state found a wrong value → screenshots at intermediate states. (10)
- Measuring memory without garbage collection gave 273 MB instead of 13 → force collection before measuring. (10)
- Jumping layout looked "unstable under load" → icon in a box matching its size. (05, 10)
- Test enshrined the bug → an old test does not prove the behavior is correct. (10)
- Generated file validated only by its own parser → open it in a real reader (spreadsheet, rendered PDF). (10)

## Device and build (stages 11 and 12)

- 11 builds before EAS Update → `expo-updates` in the first build. (12)
- Lockfile changed because of the site and the guard required a build → group dependency updates with the next build. (12)
- Tab bar below the gesture bar → add `useSafeAreaInsets().bottom`. (05)
- SVG with 100% width was cut in half on Android → measure with `onLayout` and draw in pixels. (11)
- Large font broke titles → `adjustsFontSizeToFit` and layout that shifts down with `fontScale`. (11)
- Button disappeared on short phones → main action pinned to the footer; check at 375×667. (05)
- Expo Go stopped working with a native module → development build. (11)
- Preview port already used by another app and screenshot captured the wrong app → check port and title. (00)

## Accounts and stores (stages 7, 13, 14)

- Two projects with the same name in Google Cloud → always check the ID. (07)
- Callable started locked after creation failed → delete and recreate. (07)
- Upload failed in a new project with a generic error → Storage agent role for rules that read Firestore. (07)
- Web OAuth client did not exist → enable the Google provider in the console first. (07)
- Key pasted in chat → revoke immediately; the copy dies with it. (07)
- Library brought a photos permission blocked by Play → list AAB permissions and block unused ones. (14)
- Never-published app cannot be submitted for review through the API → first submission through the Console. (14)
- Legal text with 3 false promises → check every sentence with grep in the code. (14)
- Apple keywords count bytes → store text as code with a test. (14)
- RevenueCat wizard created a generic entitlement → check against the plans decision. (13)
- Apple test purchase did not appear → paid apps agreement (bank, tax, W-8BEN) active first. (13)
- Prod Remote Config never published → switches at defaults; publish. (07)
